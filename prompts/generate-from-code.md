# Промпт: тесты из кода (АНТИПРИМЕР)

> Сценарий демо A, слайд 3. Этот промпт показывает, как **не надо**: агенту дают исходный код,
> и он берёт ожидаемое поведение из реализации. Тест проходит и закрепляет дефект как «норму».

## Вход

Исходный код класса целиком, например `src/main/java/demo/text/TextUtils.java`.

## Промпт

```text
Вот класс TextUtils:

<вставить содержимое src/main/java/demo/text/TextUtils.java>

Напиши JUnit 5 тесты, которые обеспечат 100% покрытие.
Положи в src/test/java/demo/fromcode/, пометь класс @Tag("from-code").
```

## Запуск

```bash
mvn -B test -Pdemo-from-code   # зелёный: дефект закреплён тестом
```

## Что показать

Ассерт `assertTrue(TextUtils.equals("ABC", "abc"))`: CI зелёный, покрытие 100%, баг записан в тест как ожидаемое поведение.
