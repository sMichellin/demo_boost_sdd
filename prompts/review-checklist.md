# Чеклист ревью (точка входа человека №2)

Чеклист принимает **человек**. Агент не ставит галочки (правило из `AGENTS.md`).
Цифры гейтов приходят из CI, чеклист проверяет то, что машина проверить не может.

- [ ] **Сценарии соответствуют намерению.** Спека описывает то, что действительно нужно бизнесу, а не то, что уже делает код.
- [ ] **Тесты проверяют THEN, а не реализацию.** Ожидаемые значения взяты из сценария; нет ассертов, повторяющих текущее поведение кода.
- [ ] **Mutation score не упал.** Сравнить значение в отчёте о качестве с `main`; выжившие мутанты разобраны.
- [ ] **Нет тестов из кода в `fromspec/`.** Каждый тест в `src/test/java/demo/fromspec/` помечен ID существующего сценария, тег `from-code` там не используется.
- [ ] **Неоднозначности сняты.** Если агент задавал вопросы по сценарию, ответы отражены в спеке, а не только в коде.
